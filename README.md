# OCamleer

**OCamleer**-ն ուղեցույց է՝ նվիրված OCaml ծրագրավորման լեզվին և նրա էկոհամակարգին։ Հոդվածները գրված են հայերեն և նախատեսված են ֆունկցիոնալ ծրագրավորման հայեցակարգին ծանոթանալ ցանկացող ուսանողների և ծրագրավորողների համար։
