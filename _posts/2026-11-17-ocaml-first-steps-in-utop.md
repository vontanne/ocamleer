# Խոսելով OCaml-ի հետ. առաջին քայլերը utop-ում

[Նախորդ հոդվածում](./2026-11-15-ocaml-development-environment.md) մենք տեղադրել և կարգավորել ենք OCaml-ը և նրա գործիքները, տպել ենք «Hello, world!» տեքստը, նախ utop-ում, ապա՝ ֆայլից։ Հիմա եկեք սովորենք իսկապես «խոսել» OCaml-ի հետ՝ ինչ մուտքագրել, ինչպես կարդալ և վերլուծել դրա պատասխանները։

Այս հոդվածում ամեն ինչ տեղի է ունենում utop-ում։ Ընթերցելիս utop-ը բաց պահեք և ինքներդ փորձեք յուրաքանչյուր օրինակ, դա է սովորելու ամենաարագ ճանապարհը։

## utop-ի մեկնարկ

Բացեք տերմինալ և գործարկեք՝

```sh
utop
```

utop-ը ցուցադրում է ողջույնի հաղորդագրություն, կարգավիճակի տող՝ ժամով և հրամանների հաշվիչով, և այնուհետև մուտքային հրահանգի տողը՝

```text
utop #
```

Այդ տողից ներքև կա անուններով լի մի գոտի, ինչպիսիք են `Arg`, `Array`, `ArrayLabels` և այլն․․․ Սա լրացման գոտին է։ Մենք դրան կանդրադառնանք հետագա հոդվածներից մեկում։

## utop֊ը որպես հաշվիչ

Մուտքագրեք այս տողը և սեղմեք Enter:

```ocaml
1 + 2;;
```

Վերջում գտնվող զույգ կետ-ստորակետերը `;;` utop-ին ցույց են տալիս, որ մուտքագրումն ավարտված է և այն կարող է գործարկվել: Առանց դրանց utop-ը ենթադրում է, որ դուք շարունակելու եք մուտքագրել:

utop-ը պատասխանում է՝

```text
- : int = 3
```

Պատասխանն ունի երեք մաս՝

- `-`, արդյունքն անուն չունի։ Այսինքն արժեքը հաշվել ենք, բայց դրան անուն չենք տվել։
- `: int`, երկու կետից հետո՝ արդյունքի տիպը։ `int`-ը նշանակում է ամբողջ թիվ (integer)։
- `3`, հավասարության նշանից հետո՝ արժեքը։

Կարդացեք ամբողջ տողը որպես «արդյունքը `int` տիպի է, հավասար է 3֊ի»։

Փորձեք ևս մի քանիսը՝

```ocaml
2 + 3 * 4;;
(2 + 3) * 4;;
7 / 2;;
```

```text
- : int = 14
- : int = 20
- : int = 3
```

Սկզբից կատարվում է բազմապատկումը, հետո՝ գումարումը, ինչպես մաթեմատիկայում, իսկ փակագծերը փոխում են հերթականությունը։ Վերջին արդյունքը սխալ չէ. մեկ ամբողջ թվի բաժանումը մյուսի վրա տալիս է ամբողջ թիվ, իսկ կոտորակային մասն անտեսվում է։

## Ամեն ինչ արտահայտություն է

Մինչ այժմ մուտքագրած յուրաքանչյուր կոդի կտորը **արտահայտություն** է՝ կոդ, որը OCaml-ը կարող է հաշվել։ Արտահայտության հաշվարկի արդյունքն արժեք է։ Արժեքն այլևս չի կարող պարզեցվել. `3`-ն արժեք է, մինչդեռ `1 + 2`-ն արտահայտություն է, որի արժեքը `3`-ն է։

OCaml-ը հաշվում է արտահայտությունը քայլ առ քայլ.

```text
(1 + 2) * (10 - 4)
3 * (10 - 4)
3 * 6
18
```

Ստուգեք վերջնական պատասխանը utop-ում:

```ocaml
(1 + 2) * (10 - 4);;
```

```text
- : int = 18
```

Արտահայտությունները միայն թվերով չեն սահմանափակված։ `^` օպերատորը միացնում է երկու տողերը։

```ocaml
"Hello, " ^ "world!";;
```

```text
- : string = "Hello, world!"
```

Նույնիսկ պայմանի ստուգումն է արտահայտություն:

```ocaml
if 3 > 2 then "yes" else "no";;
```

```text
- : string = "yes"
```

Շատ լեզուներում `if`-ը հրահանգ է, որն ինչ-որ բան է անում, բայց արժեք չի վերադարձնում։ OCaml-ում `if ... then ... else ...`-ը հաշվարկում է արժեք, ինչպես `1 + 2`-ը։ Հենց սա ի նկատի ունենք, երբ ասում ենք, որ OCaml-ում ամեն ինչ արտահայտություն է. ծրագրերը կառուցված են արժեքներ հաշվարկող արտահայտություններից։

Իսկ ուղղակի տեքստ տպելու մասին ի՞նչ կարող ենք ասել: Եկեք կրկնենք նախորդ հոդվածի օրինակը:

```ocaml
print_endline "Hello, world!";;
```

```text
Hello, world!
- : unit = ()
```

Առաջին տողն էկրանին տպվող տեքստն է: Դա արտահայտության հաշվարկի **կողմնակի ազդեցությունն** է՝ այն, ինչ արտահայտությունն անում է բացի արժեքը հաշվարկելուց: Երկրորդ տողը utop-ի սովորական պատասխանն է․ արտահայտության արժեքը `()` է, իսկ նրա տիպը՝ `unit`։ `()` արժեքը որևէ տեղեկություն չի պարունակում։ `print_endline`-ի նման ֆունկցիաներն այն վերադարձնում են, քանի որ ցանկացած ֆունկցիա պարտադիր պետք է արժեք վերադարձնի։ Սակայն print_endline ֆունկցիայի իրական գործը կողմնակի ազդեցությունն է, այս պարագայում՝ ինտերակտիվ միջավայրի կոնսոլում "Hello, world!" տեքստն արտածելը։

## Տիպերի մասին

utop֊ի յուրաքանչյուր պատասխան պարունակում է արժեքի **տիպի** մասին ինֆորմացիա։ Տիպը սահմանում է, թե տվյալն ինչ արժեքներ կարող է ունենալ և ինչ գործողություններ կարելի է կատարել դրա հետ։ Փորձեք այս արժեքները հերթով՝

```ocaml
42;;
3.14;;
"OCaml";;
true;;
```

```text
- : int = 42
- : float = 3.14
- : string = "OCaml"
- : bool = true
```

Մենք արդեն հանդիպել ենք ևս մեկ տիպի՝ `unit`-ի, `print_endline`-ի պատասխանում: Այս տիպն ունի միայն մեկ արժեք, որը գրվում է `()` և արտասանվում է «unit»: Դուք կարող եք ինքներդ մուտքագրել այն՝

```ocaml
();;
```

```text
- : unit = ()
```

`()`-ը պարզապես նշանակում է, որ արտահայտության հաշվարկն ավարտվել է և իմաստալից արդյունք չկա։ Սա է պատճառը, որ կողմնակի ազդեցության համար օգտագործվող արտահայտություններն ունեն `unit` տիպը։

Ահա այն հինգ տիպերը, որոնց հետ մենք արդեն ծանոթ ենք՝

| Տիպ      | Ի՞նչ է դա                                        | Օրինակներ            |
| -------- | ------------------------------------------------ | -------------------- |
| `int`    | ամբողջ թվեր                                      | `42`, `-7`, `0`      |
| `float`  | կոտորակային մասով (լողացող ստորակետով) թվերի տիպ | `3.14`, `2.0`        |
| `string` | կրկնակի չակերտներով տեքստ                        | `"OCaml"`, `"Hello"` |
| `bool`   | տրամաբանական արժեքներ                            | `true`, `false`      |
| `unit`   | իմաստալից արժեքի բացակայություն                  | `()`                 |

Յուրաքանչյուր արժեք ունի ճիշտ մեկ տիպ։ `42`-ը `int` է, իսկ `42.0`-ը՝ `float`։ Մեզ համար դրանք նման են, սակայն OCaml-ի կոմպիլյատորի համար դրանք տարբեր տիպերի տարբեր արժեքներ են։

Տիպերը սահմանում են, թե որ արժեքների հետ ինչ գործողություններ են թույլատրվում։ `+` օպերատորը գումարում է միայն ամբողջ թվերը։ Կոտորակային մասով թվերի համար կա իր սեփական գումարման օպերատորը՝ `+.` կետով։

```ocaml
1.5 +. 2.0;;
```

```text
- : float = 3.5
```

## Ամփոփում

- utop-ը գործարկում է ձեր մուտքագրած արտահայտությունը, երբ այն ավարտվում է `;;`-ով, իսկ արտածվող պատասխանը ներառում է արժեքն ու դրա տիպը `- : int = 3`։
- Կոդը բաղկացած է արտահայտություններից։ Արտահայտության հաշվարկը վերադարձնում է արժեք։ Նույնիսկ `if`-ը արտահայտություն է։
- Ամբողջ թվերի և կոտորակային մասով թվերի օպերատորները տարբեր են, օրինակ գումարման դեպքում՝ `+` ամբողջ թվերի համար և `+.` լողացող ստորակետով թվերի համար։
