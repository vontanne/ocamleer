# Փոփոխականներ առանց վերագրման

[Նախորդ հոդվածում](./2026-11-17-ocaml-first-steps-in-utop.md) ամեն արդյունք մեկ անգամ էր հայտնվում էկրանին, և այն կրկին օգտագործելու համար ստիպված էինք արտահայտությունը նորից մուտքագրել։ Այս անգամ կսովորենք արժեքին անուն տալ։ Ինչպես նախորդ անգամ, բաց պահեք utop-ը և հերթով փորձեք օրինակները։

## Արժեքին անուն տալը

Մուտքագրեք հետևյալ տողը և սեղմեք Enter ստեղնը։

```ocaml
let x = 5;;
```

utop-ը պատասխանում է․

```text
val x : int = 5
```

Համեմատենք սա նախորդ հոդվածում ստացած առաջին պատասխանի հետ՝ `- : int = 3`։ Այնտեղ `-` նշանը ցույց էր տալիս, որ արդյունքն անուն չունի։ Այժմ պատասխանը սկսվում է `val x` գրառումով․ արժեքն ունի անուն՝ `x`։ Մնացածն արդեն ծանոթ է․ `int`-ը տիպն է, իսկ `5`-ը՝ արժեքը։

`let` ծառայողական բառով `=` նշանից ձախ գրված անունը կապում ենք աջ կողմում գրված արժեքի հետ։ Սա կոչվում է **կապակցում** (անգլերեն՝ _binding_)։ Մեր օրինակում `x` անունը _կապեցինք_ `5` արժեքի հետ։ Այսուհետ, երբ մեզ պետք է այդ արժեքը, կարող ենք գրել `x`։

```ocaml
x + 1;;
x * x;;
```

```text
- : int = 6
- : int = 25
```

Այս արդյունքներին անուն չենք տվել, ուստի utop-ի երկու պատասխաններն էլ սկսվում են `-` նշանով։

Անուն կարելի է տալ ցանկացած արժեքի՝ լինի դա թիվ, տող, թե տրամաբանական արժեք։

```ocaml
let greeting = "Hello";;
let pi = 3.14159;;
let is_ready = true;;
```

```text
val greeting : string = "Hello"
val pi : float = 3.14159
val is_ready : bool = true
```

## Օգտագործենք արդեն սահմանված անունները

`let`-ով անուն սահմանելիս `=` նշանից աջ կարող է լինել ցանկացած արտահայտություն։ Դրանում կարող ենք օգտագործել նաև արդեն սահմանված անուններ։

```ocaml
let width = 8;;
let height = 5;;
let area = width * height;;
```

```text
val width : int = 8
val height : int = 5
val area : int = 40
```

OCaml-ը նախ հաշվում է `width * height` արտահայտության արժեքը, ապա `area` անունը կապում է ստացված արդյունքի՝ `40`-ի հետ։ Երբ հաջորդ տողերում գրում ենք `area`, ստանում ենք արդեն հաշվված արժեքը։ Բազմապատկումը նորից չի կատարվում։

Մենք ոչ մի տեղ `int` չգրեցինք։ OCaml-ը գիտի, որ `width`-ն ու `height`-ն ամբողջ թվեր են։ Հետևաբար `width * height` արտահայտության արդյունքը նույնպես ամբողջ թիվ է, և `area`-ի տիպը `int` է։ Տիպերի այսպիսի ավտոմատ որոշումը կոչվում է **type inference**։

## Չկապակցված անուններ

Եթե օգտագործենք մի անուն, որը որևէ արժեքի հետ չենք կապել, OCaml-ը կհայտնի սխալի մասին։ Փորձենք, օրինակ, `width`-ը գրել տառասխալով։

```ocaml
widht;;
```

```text
Error: Unbound value widht
Hint:   Did you mean width?
```

_Unbound_ նշանակում է «չկապակցված»։ OCaml-ին հայտնի չէ `widht` անունով որևէ արժեք։ Քանի որ կա նման անուն՝ `width`, OCaml-ն առաջարկում է այն։

Մինչև հիմա `let`-ը գրել ենք անմիջապես utop-ի հրահանգի տողում՝ որևէ այլ արտահայտությունից դուրս։ Այդպես ստեղծված կապակցումները կոչվում են **վերին մակարդակի կապակցումներ** (անգլերեն՝ _top-level bindings_)։ Այդ անուններից յուրաքանչյուրը կարող ենք օգտագործել հաջորդ տողերում։ Եթե դուրս գանք utop-ից ու նորից գործարկենք այն, այդ անուններն այլևս հասանելի չեն լինի։ [Միջավայրի կարգավորման մասին հոդվածից](./2026-11-15-ocaml-development-environment.md) արդեն ծանոթ `hello.ml` ֆայլում `let`-ը նույն կերպ կաշխատի։ Ուղղակի ֆայլում տողերի վերջում `;;` դնելու կարիք չկա։

## Փոփոխականների կապակցման և վերագրման տարբերությունը

Եթե ծանոթ եք Python-ին, JavaScript-ին, C-ին կամ Java-ին, `let x = 5` գրառումը տեսնելիս հավանաբար կմտածեք, որ փոփոխական ենք ստեղծում։ Սակայն մի շատ կարևոր տարբերություն երևում է, հենց փորձում ենք փոխել արժեքը։

Շատ պարզեցված մոդելով, այդ լեզուներում փոփոխականը կարելի է պատկերացնել որպես տուփ։ Փոփոխականը _հայտարարելը_ նման է տուփ ստեղծելուն, իսկ փոփոխականին արժեք _վերագրելը_՝ այդ տուփի մեջ արժեք դնելուն։ Հետո կարող ենք արժեքը փոխարինել մեկ ուրիշով։ Եթե Python-ում `count = 0` տողից հետո գրենք `count = count + 1`, ապա `count` անունն արդեն կնշանակի `1`։ C-ում կամ Java-ում կարելի է նույնիսկ փոփոխական հայտարարել՝ առանց դրան արժեք տալու (int count;), և արժեքը վերագրել ավելի ուշ: JavaScript-ում էլ գործածվում է նույն `let` բառը, բայց դրանով հայտարարված փոփոխականին հետագայում կարելի է նոր արժեք վերագրել։

OCaml-ում անունը պատկերացրեք որպես արժեքին փակցված պիտակ։ Այստեղից երկու բան է հետևում։

**Կապակցված անունը միշտ արժեք ունի։** Չենք կարող «դատարկ» անուն հայտարարել ու հետո միայն դրան արժեք տալ։ `let x;;` գրառումն անավարտ է, և utop-ը պատասխանում է `Error: Syntax error`։

**Կապակցված անվանը նոր արժեք վերագրել հնարավոր չէ։** Փորձենք գրել այն, ինչն այլ լեզուներում վերագրում է նշանակում։

```ocaml
x = 10;;
```

```text
- : bool = false
```

`let`-ից անկախ օգտագործվելիս `=` նշանը ստուգում է երկու արժեքների հավասարությունը։ Այն համեմատության նշան է, ինչպես `>`-ը՝ `3 > 2` արտահայտության մեջ։ «`x`-ը հավասա՞ր է `10`-ի» հարցին utop-ը պատասխանեց `false`։ Իսկ `x`-ի արժեքը շարունակվեց մնալ `5`։

Եթե կրկին գրենք `let` և նշենք նույն `x` անունը, կստեղծենք նոր կապակցում։ Հին կապակցումը կմնա անփոփոխ, բայց հետագա տողերում `x` անունն արդեն ցույց կտա նոր արժեքը։ Այսպես նոր կապակցումը **թաքցնում է նախորդը** (անգլերեն՝ _shadowing_)։

Առաջին հայացքից սա կարող է սահմանափակում թվալ, բայց այդպես ծրագիրն ավելի հեշտ է կարդալ։ Անունն արժեքի հետ կապելուց հետո այդ կապն անփոփոխ է մնում։ Ուստի կարիք չկա կոդի մյուս տողերում ստուգելու, թե արդյոք որևէ տեղ այդ անվանը նոր արժեք են վերագրել։ OCaml-ում էլ `x`-ն անվանում են _փոփոխական_՝ բառի մաթեմատիկական իմաստով․ այն որևէ արժեք նշանակող անուն է։

## Փոփոխականի անվանման ընտրությունը

[OCaml-ի ձեռնարկում](https://ocaml.org/manual/latest/lex.html) արժեքների անունների համար սահմանված են հետևյալ կանոնները։

- Անունը սկսեք փոքրատառով։ Առաջին նիշը կարող է լինել նաև `_`, բայց այդպիսի անունները հատուկ կիրառություն ունեն, ուստի առայժմ նախընտրեք տառը։
- Առաջին նիշից հետո կարող եք գրել տառեր, թվանշաններ, ընդգծման նշաններ (`_`) և ապաթարցներ (`'`)։
- Որպես անուն չեք կարող օգտագործել **ծառայողական բառ** (անգլերեն՝ _keyword_)՝ լեզվում հատուկ նշանակություն ունեցող բառ, օրինակ՝ `let`, `if`, `then`, `else`, `true`, `false`, `type` կամ `end`։

| Անուն         | Թույլատրելի՞ է | Պատճառը                                                          |
| ------------- | -------------- | ---------------------------------------------------------------- |
| `max_speed_2` | Այո            | Սկսվում է տառով, պարունակում է տառեր, `_` նշաններ և մեկ թվանշան։ |
| `x'`          | Այո            | Տառին հաջորդում է ապաթարց։                                       |
| `2nd_place`   | Ոչ             | Սկսվում է թվանշանով։                                             |
| `Total`       | Ոչ             | Մեծատառով սկսվող անունները լեզվում այլ կիրառություն ունեն։       |
| `total-price` | Ոչ             | OCaml-ը սա կարդում է որպես հանում՝ `total - price`։              |
| `type`        | Ոչ             | Ծառայողական բառ է։                                               |

Այստեղ «տառ» ասելով նկատի ունենք լատինական հիմքով տառերը՝ անգլերենի այբուբենի տառերը և որոշ լրացուցիչ տառեր, օրինակ՝ `é`։ Հայերեն տառերն անուններում չենք կարող օգտագործել։

```ocaml
let տարի = 2026;;
```

```text
Error: Line 1, characters 4-12:
Error: Invalid character U+057F in identifier
```

`U+057F`-ը `տ` տառի կոդն է Յունիկոդում։ Դա առաջին տառն է, որը OCaml-ը մերժեց այս անվան մեջ։

### snake_case

Եթե անունը մի քանի բառից է կազմված, բառերն իրար միացրեք ընդգծման նշանով, ինչպես `user_name` և `max_speed` անուններում։ Գրության այս ոճը կոչվում է **snake_case**։ OCaml-ն ընդունում է նաև `userName` ձևը (_camelCase_, որը տարածված է Java-ում և JavaScript-ում)։ [OCaml-ով ծրագրավորելու ուղեցույցը](https://ocaml.org/docs/guidelines) խորհուրդ է տալիս բառերն առանձնացնել ընդգծման նշանով։ Այդ սկզբունքին հետևում է նաև ստանդարտ գրադարանը․ օրինակներից է `print_endline` անունը։ Ընտրեք նաև այնպիսի անուն, որից պարզ լինի, թե ինչ է այն նշանակում․ `area` («մակերես») անունն ավելի խոսուն է, քան `a`-ն։

### Ապաթարցը

Ինչպես մաթեմատիկայում, այստեղ էլ անվան վերջում դրված ապաթարցը կարդում ենք «շտրիխ» (անգլերեն՝ _prime_)։ Օրինակ՝ `x'` («իքս շտրիխ») անունով կարող ենք նշել `x`-ի հետ առնչվող մեկ այլ արժեք։

```ocaml
let x = 7
let x' = x + 1;;
```

```text
val x : int = 7
val x' : int = 8
```

Ապաթարցը չափավոր օգտագործեք․ սովորաբար `next_x`-ի նման անունն ավելի հստակ և ընթեռնելի է։

## Ամփոփում

- `let name = expression;;` գրելիս OCaml-ը հաշվում է արտահայտության արժեքը և անունը կապում է ստացված արդյունքի հետ։ utop-ը պատասխանում է `val name : type = value` ձևով։
- Չկապակցված անուն օգտագործելիս ստանում ենք `Unbound value` հաղորդագրությունը։
- Կապակցված անունը միշտ արժեք ունի։ Այդ անվանը նոր արժեք վերագրել հնարավոր չէ։ `x = 10`-ի նման արտահայտության մեջ `=` նշանը համեմատում է արժեքները։
- Անունը սովորաբար սկսում ենք փոքրատառով։ Առաջին տառից հետո կարող ենք գրել նաև թվանշաններ, `_` և `'`։ Ծառայողական բառը չի կարող փոփոխականի անուն լինել։ Մի քանի բառից կազմված անունների համար ընդունված է `snake_case` ոճը։
